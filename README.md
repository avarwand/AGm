# AGm | Avarwand Git Manager

**AGm (Avarwand Git Manager)** is a graphical Git repository management tool for working with multiple local repositories from one convenient interface.

It simplifies common Git tasks and provides an easy way to monitor, manage, and work with multiple repositories simultaneously.

## Features

* **Repository Profiles**: Manage multiple local Git repositories in one place.
* **Git Operations**: Perform common operations such as status, pull, push, commit, fetch, stage, stash, and more.
* **Batch Operations**: Run Git operations across multiple selected repositories.
* **Repository Status**: Quickly see which repositories are synchronized or have changes.
* **Interactive CLI**: Access Git commands through an integrated terminal interface.
* **Repository Cloning**: Clone remote repositories directly from AGm.
* **Submodule Management**: Add and remove Git submodules.
* **Configuration**: Save and manage application settings and repository profiles.
* **Modern Interface**: Clean, dark-themed, customizable graphical interface.
 
## System Requirements

* Windows 10 or later
* Git installed and available on the system PATH

AGm is distributed as a standalone application, so Python is not required.

## Typical Uses

AGm can be useful for:

* Managing multiple Git repositories
* Performing repetitive Git operations
* Monitoring repository status
* Working with repositories during development
* Managing Git submodules
* Quickly accessing Git commands

## Git Compatibility

AGm works with standard Git repositories and can be used with repositories hosted on services such as GitHub, GitLab, Bitbucket, and other Git-compatible platforms.
